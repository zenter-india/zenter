# Content Rights

## Code-level check

Zenter displays no licensed, streamed, or embedded third-party media content. It has:
- No video/audio streaming feature
- No embedded web content beyond outbound `Linking.openURL` calls to the OS browser (tel:, mailto:, and the
  app's own zenter.in pages)
- No third-party content library, no music/video SDK, no news/article aggregation

All visible content is either (a) app-authored UI/copy, or (b) user-generated (profile fields, chat messages —
owned by the users who wrote it, not licensed third-party content).

## App Store Connect answer

> **Does your app contain, display, or access third-party content?** → **No**

**OWNER ACTION REQUIRED**: none identified — this is a low-ambiguity "No" based on the actual feature set. If
future versions add embedded maps, streamed content, or licensed media, revisit this answer then.
